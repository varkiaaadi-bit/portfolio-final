# Aadi Varkia — Portfolio

A modern, responsive static portfolio website built from Aadi Varkia's CV.

## Deploy on Vercel

### Option 1 — GitHub (recommended)
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Vercel and import the GitHub repository.
4. Framework preset: **Other**
5. Build command: leave empty.
6. Output directory: leave empty / root.
7. Deploy.

### Option 2 — Vercel CLI
Install Node.js, then run:

```bash
npm i -g vercel
vercel
```

When prompted, select the project directory and deploy.

## Notes
- This is a static site, so no build step is required.
- **Profile Photo**: Place your photo as `profile.jpg` in the root directory to display your personal photo in the Hero section.
